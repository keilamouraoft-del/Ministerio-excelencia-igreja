# Objetivos do Projeto

## 1. Objetivo geral

Desenvolver um aplicativo para organizar a programação dos cultos da Igreja.

## 2. Objetivos específicos

- Facilitar a montagem da programação dos cultos.
- Organizar os momentos do culto em uma sequência definida.
- Permitir o cadastro e a reutilização dos nomes dos participantes.
- Facilitar o ajuste dos horários.
- Permitir visualizar, compartilhar e imprimir a programação.
- Tornar o aplicativo simples e acessível para diferentes usuários.

## 3. Objetivo dos testes

Verificar se as funcionalidades do aplicativo funcionam conforme os requisitos definidos, identificando falhas e registrando os resultados dos testes.
