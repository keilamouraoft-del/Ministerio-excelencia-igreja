# Regras de Negócio

## RN-001 — Ordem da programação
Os momentos devem aparecer na ordem definida pelo usuário.

## RN-002 — Exclusão de momentos
Ao excluir um momento, os demais devem permanecer na programação.

## RN-003 — Horários
Os horários devem respeitar os ajustes realizados pelo usuário.

## RN-004 — Horários fixados
Os horários fixados pelo usuário não devem ser alterados automaticamente.

## RN-005 — Sugestão de nomes
O sistema deve sugerir nomes já cadastrados ou utilizados anteriormente.

## RN-006 — Somente vídeo
Quando a opção "Somente o vídeo (sem fala)" estiver selecionada, o campo de nome da pessoa deve ficar desabilitado.

## RN-007 — Cópia de nomes
Quando previsto na programação, o nome de uma pessoa deve ser copiado automaticamente para o momento relacionado, permitindo edição quando necessário.

## RN-008 — Momento não realizado
A opção "Não haverá" deve permanecer visível quando selecionada, até que o usuário exclua o momento.

## RN-009 — Limpar programação
O sistema deve solicitar confirmação antes de limpar os dados preenchidos.
