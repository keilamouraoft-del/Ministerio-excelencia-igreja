# Requisitos Funcionais

## RF-001 — Montar a programação
O sistema deve permitir montar a programação do culto com os momentos previstos.

## RF-002 — Adicionar momentos
O sistema deve permitir adicionar novos momentos à programação.

## RF-003 — Excluir momentos
O sistema deve permitir excluir momentos da programação.

## RF-004 — Ordenar momentos
O sistema deve permitir alterar a ordem dos momentos.

## RF-005 — Definir horários
O sistema deve permitir definir e editar os horários dos momentos.

## RF-006 — Cadastrar participantes
O sistema deve permitir informar os nomes das pessoas responsáveis por cada momento.

## RF-007 — Reutilizar nomes
O sistema deve sugerir nomes já utilizados para facilitar o preenchimento.

## RF-008 — Visualizar programação
O sistema deve permitir visualizar a programação antes de finalizá-la.

## RF-009 — Compartilhar programação
O sistema deve permitir compartilhar a programação com outras pessoas.

## RF-010 — Imprimir programação
O sistema deve permitir imprimir a programação.

## RF-011 — Limpar preenchimento
O sistema deve permitir limpar os dados preenchidos mediante confirmação.

## RF-012 — Registrar observações
O sistema deve permitir inserir observações na programação.
